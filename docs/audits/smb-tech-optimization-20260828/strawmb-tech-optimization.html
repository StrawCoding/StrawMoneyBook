2. 手法目錄

每一項：現況 → 手法 → 邊界 → 之後怎麼驗。實作須另開階段，本報告不改碼。

2.1 Query pushdown

P0 剩餘 聚合與分頁進 SQLite，熱路徑禁止 listAllTransactionsChunked。

現況：分析主頁已 SQL。分類明細在「全部」仍把整本帳本載入再於 JS 篩分類：

AnalysisCategoryDetailPage.vue L221–228
  listTransactionsForAnalysis(ledgerId, { mode, key })
    → listTransactionsByScope  L36–56
      mode=all → listAllTransactionsChunked(ledgerId)
    註：year/month 走 listTransactionsByYear/Month；day 未從 UI 傳 key 時 key=''

手法：明細改 listTransactionsByCategoryPage（ledger + category + type + scope + LIMIT/OFFSET），語意對齊現有 refund／include_in_analysis／排除 loan_payment。不要在頁面再掃全表。

邊界：報表匯出（PDF/CSV）需要列資料，可保留 chunked 路徑；不得當分析互動熱路徑。

驗收：sql.js 對齊 breakdown 列集合；mode=all 路徑測試禁止呼叫 listAllTransactionsChunked；playwright:analysis-export 不回退。

2.2 Staged hydration

部分 DONE 帳本 critical path 已抽到 ledger-runtime.service.js（186 行）。

仍阻塞 first paint 前的 JS：

  1. main.js 模組求值：FontAwesome 全量 import + library.add（見 2.4），發生在 main() 之前。
  2. app.mount('#app') 之後才 await initSqliteWebStoreWithTimeout()（L378–381），再 bootstrapApp + installAppRuntime。殼先上、資料後到——這是對的；成本在 FA 與 sqlite wasm。

手法：不要把更多工作塞回 main.js。FA 子集（2.4）；runtime job 繼續走 runtime-job-scheduler.js（已有 coalesce／anti-reentry，53 行）。

驗收：行為測試（sql.js／Playwright）證明首屏帳戶／分類／目前預算先完成；完整性掃描與借貸／報銷仍背景。禁止只靠 source assert.match。

2.3 渲染虛擬化

P2 已套 content-visibility: auto + contain-intrinsic-size: auto 72px：

  • 首頁交易流 HomeTransactionFeed.vue L423–424
  • 搜尋 TransactionSearchPage.vue L293–294（資料本身已分頁 300，listTransactionsForSearch L142–161）

未套：AccountDetailPage.vue（1053 行，資料已 listTransactionPageForAccount 分頁）、AnalysisCategoryDetailPage.vue（536 行，資料仍可能全量）、請款單各列表。

手法：同一 CSS 契約即可，不必上 VirtualList 函式庫。優先套「會全量渲染」的分類明細；已分頁列表收益較小。

驗收：Playwright 捲動仍可點列；source CSS match 不是驗收。

2.4 啟動與 bundle — FontAwesome 全量註冊

P0 main.js 419 行，幾乎全是 fa* import。獨特符號 162 個，library.add(...icons) 在 L360–365 同步執行。Vite 已把 @fortawesome 切到 vendor-icons chunk——不降低 parse／execute 成本。

手法：只註冊實際用到的 icon（從 template／對照表蒐集），或按 route 懶註冊。不要再為 FA 開空 chunk。

邊界：漏註冊會變空白圖示；必須用 i18n／icon picker 實際集合當權威，禁止猜。

驗收：playwright:ui-layout 斷言首頁／BottomNav／功能列表 FontAwesome 仍渲染；bundle 報告 main 模組不再含完整 icon 表。

驗收：既有 membership／Play 測試 PASS；免費額度錯誤碼不變。
