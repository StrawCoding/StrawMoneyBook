1. 目標與結論

  • 啟用上線：以 VITE_BANK_SYNC_FEATURE_ENABLED 環境變數控制功能開關，取代硬編碼關閉。
  • 移除 Sandbox：生產路徑不再暴露 mock_bank_tw；舊測試連線在 UI 標示為已停用。
  • UX 優化：新增建立連線 Wizard、批次帳戶儲存、待匯入 badge、進階設定收合。
  • 保留擴充性：Provider registry（VITE_BANK_SYNC_PROVIDERS_JSON）與 native / remote API 抽象層維持不變。
  • 開放對象：會員限定；真實同步目前僅支援 Android App + 第一銀行。

5. 環境變數與啟用條件

變數 建議值（Android 發版） 說明
VITE_BANK_SYNC_FEATURE_ENABLED true 主功能開關；關閉時入口與路由 guard 皆隱藏
VITE_BANK_SYNC_ENABLE_UNSUPPORTED_REAL_PROVIDERS true 允許第一銀行真實 provider（opt-in）
VITE_BANK_SYNC_API_BASE_URL 可留空（Android native） 僅遠端 API 整合時需要；Android 本地自動化不需部署
VITE_BANK_SYNC_PROVIDERS_JSON 可選 覆寫 provider 清單；未設定時預設僅 first_bank_tw

功能可見條件（邏輯）

isBankSyncFeatureEnabled()
  = VITE_BANK_SYNC_FEATURE_ENABLED === true
  AND listBankProviders().length > 0
  AND（Android native 環境 OR 已設定遠端 API）
