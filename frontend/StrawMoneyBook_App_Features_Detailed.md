# StrawMoneyBook App 特色與特點（細緻版）

> 這份文件聚焦「產品特色」與「實際使用價值」，不是程式碼索引。
> 如需檔案對應關係，請搭配 `StrawMoneyBook_Features_Map.md` 閱讀。

## 1. 產品定位

StrawMoneyBook 是一款以**日常記帳 + 現金流追蹤 + 進階情境管理**為核心的行動記帳 App。  
它不是只記「收入/支出」而已，而是把常見的金流場景一起整合：

- 多帳本切換（工作 / 家庭 / 個人分開）
- 預算控制（按月份與分類檢視）
- 預算日均規則（可用星期 / 日期計算分類預算）
- 借貸管理（借出 / 借入、還款、作廢）
- 報銷流程（未報銷 / 已報銷與入帳處理）
- 請款單流程（建立請款、導入報銷、完成請款、刪除）
- 存錢罐（存入 / 提取、目標進度、可排除資產）
- 備份與還原（本機匯出、雲端自動備份、Google 自動登入恢復）
- 分析與報表（圖表 + CSV / PDF 匯出）
- App 更新檢查（Android 使用 Google Play 狀態檢查）

## 2. 核心特色（使用者角度）

### 2.1 一次完成「記帳 + 補充資訊」

在首頁快速新增（Quick Add）中，除了金額、帳戶、分類、時間，還可補充：

- 備註
- 可報銷標記
- 附加金額項目（可加可減）

這讓使用者在「當下」就把交易情境記完整，不用事後回補。

### 2.2 多種交易型態，降低誤記風險

支援下列交易型態：

- 支出
- 收入
- 轉帳
- 調整

不同型態對應不同欄位與驗證邏輯，可降低把轉帳誤記成支出的情況。

### 2.3 多帳本設計，生活與工作可分流

可建立並切換不同帳本，適合：

- 個人生活帳
- 家庭共用帳
- 小型專案 / 副業帳

切換帳本後，首頁、分析、借貸、報銷、備份都會使用同一帳本上下文，資料不混雜。

### 2.4 交易查找效率高（關鍵字 + 日期區間）

交易搜尋頁可用關鍵字查詢：

- 分類
- 帳戶
- 備註
- 金額
- 日期文字

並可加上起訖日期篩選，適合對帳、追蹤某筆支出、或回溯特定期間異常交易。

### 2.5 預算不只看總額，能看分類執行狀況

預算頁可按月份管理預算，並落到分類層級，幫助使用者知道：

- 哪些分類超支
- 哪些分類仍有空間
- 每月控制重點應放在哪裡

此外，分類預算已支援更貼近日常習慣的「日均規則」：

- 固定月額
- 日均（平日 / 假日 / 自訂星期）
- 日均（指定每月日期，例如 23 號）

這讓早餐、晚餐、聚餐這類高頻支出，可以用更符合實際頻率的方式規劃。

### 2.6 分析頁快速切換收入 / 支出視角

分析頁提供：

- 全部 / 年 / 月區間
- 收入與支出視角切換
- 圓餅圖 + 分類占比 + 筆數統計

可以快速理解「錢從哪裡來、花到哪裡去」。

### 2.7 借貸、報銷、請款流程內建，不靠備註硬記

很多記帳 App 會把借貸、報銷、請款塞進備註。StrawMoneyBook 則提供獨立模組：

- 借貸：借出 / 借入、還款、狀態追蹤（進行中 / 已結束 / 作廢）
- 報銷：未報銷 / 已報銷切換，並可執行報銷入帳
- 請款單：手動新增收入 / 支出項目、導入報銷、完成請款、刪除

請款單完成時，導入的報銷項目會同步標記為已報銷，避免重複追蹤。

這能明確區分「一般消費」與「暫墊款項」，提高現金流判讀準確度。

### 2.8 報銷支援代收抵扣，不把暫收款誤算成可支配資產

針對報銷場景，已支援「代收」機制：

- 代收代表提前收到、但尚未真正完成報銷的款項
- 代收可在報銷入帳時直接抵扣
- 代收金額不計入預算與分析
- 代收金額不算入資產可支配餘額
- 帳戶有代收時會額外標示代收金額

這能把「先收到款、之後才核銷」的情境與一般收入拆開。

### 2.9 AI 記帳可快速解析句子

支援自然語句輸入（例如：`午餐250信用卡牛肉麵`），可自動解析：

- 金額
- 交易型態
- 帳戶
- 分類
- 備註

並加入下列規則，讓結果更接近可直接入帳：

- 支援多語言輸入情境
- 分類盡量自動判斷，不把已識別內容重複塞進備註
- 若缺少可用分類，可直接引導使用者前往分類管理補齊

### 2.10 存錢罐是獨立的儲蓄空間，不混進日常交易帳戶

存錢罐適合用來管理「先存起來、不想當作日常可花餘額」的資金。

- 免費版可建立 1 個，會員不限數量
- 可存入、可提取，不綁固定來源帳戶
- 可自行放入帳戶群組
- 可設定目標金額並顯示進度條
- 也可設定為無上限存放
- 預設不計入資產，可自行切換是否納入

存錢罐本質上是特殊帳戶，但不允許直接做一般收支，避免把儲蓄空間當日常帳戶誤用。

### 2.11 備份 / 還原流程完整

資料管理與自動備份支援：

- 匯出所有帳本資料
- 還原前清空資料再匯入
- 還原後做一致性檢查與修復提示
- 雲端備份（WebDAV、Google Drive appDataFolder）

Google 自動備份也已加入更貼近使用習慣的行為：

- 開啟 App 會嘗試靜默恢復 Google 備份登入
- 優先沿用上一次備份使用的帳號
- 避免在背景默默切到錯的 Google 帳號

適合跨裝置延續使用情境（A 裝置備份、B 裝置還原）。

### 2.12 交易報表不只 CSV，也可直接輸出 PDF

交易報表頁除了原本的 CSV 匯出，現在也支援：

- PDF 匯出（透過列印版面輸出）
- 圖表摘要
- 完整交易明細表格

適合用於整理月結、對帳與分享給他人檢視。

## 3. 體驗特色（介面與操作）

### 3.1 行動優先的導航結構

- 底部導覽對應主要功能區
- 首頁有浮動快速新增按鈕（FAB）
- 常用操作集中在單手可觸達區

### 3.2 開關動畫完整，操作更連續

已統一開啟 / 關閉動畫行為，包含：

- App 啟動進場
- 路由切換
- Sheet / 彈層開關
- 下拉面板 / 日期面板開關
- 區塊展開收合
- Toast 進出場

這讓資訊層級切換更容易理解，降低「突然跳動」造成的負擔。

### 3.3 Android 返回鍵針對疊層優先關閉

在 Android 平台，返回鍵會先嘗試關閉當前 overlay（如 sheet），再決定是否返回頁面或退出 App。  
符合原生使用習慣，不容易誤觸離開。

### 3.4 關鍵刪除流程使用自製確認對話框

在分類、帳戶、帳本、請款單等關鍵刪除操作，採一致的自製確認 UI，減少誤刪與體驗斷裂。

### 3.5 針對行動操作做防誤觸優化

已針對手機操作補強：

- 長按連結不進入拖動狀態
- 除輸入框外，畫面文字預設不可選取

這能減少操作中出現不必要的選字、拖曳與誤觸干擾。

## 4. 技術特點（產品穩定性角度）

### 4.1 分層清楚，維護與擴充成本可控

採用 View / Store / Service / Repository 分層：

- View：畫面互動
- Store：前端狀態管理
- Service：業務規則
- Repository：資料存取

優點是功能擴充與維護成本較可控，不容易因功能增長而失序。

### 4.2 本地資料能力完整

專案使用 Capacitor + SQLite（含 Web / WASM 支援），在行動與網頁端都能維持一致的資料操作模型。  
對記帳這類高頻、要求回應快的 App 很重要。

### 4.3 內建修復與匯入匯出管道

除了日常功能，設定中也提供：

- 匯入
- 匯出
- 修復工具
- 備份與還原

對長期使用者來說，這些是「可持續使用」而不是「短期玩票」的關鍵。

### 4.4 更新與備份都偏向原生化流程

在 Android 上，更新檢查優先走 Google Play 的版本狀態資訊，而不是只靠自架 API。  
同時，Google 自動備份會在 App 啟動與回前景時嘗試恢復登入狀態。

這代表：

- 更新提示更接近實際上架狀態
- 備份流程更接近原生 App 的持續登入體驗

## 5. 與一般記帳工具的差異化

StrawMoneyBook 的差異化不在單一炫技功能，而在**金流情境整合完整度**：

- 一般記帳：收入 / 支出 + 簡單圖表
- StrawMoneyBook：收入 / 支出 + 預算 + 借貸 + 報銷 + 請款單 + 存錢罐 + AI 快速輸入 + 多端備份還原

也就是把「記錄」延伸到「管理與追蹤」，特別適合：

- 有多帳本需求的人
- 常有墊付款 / 借貸往來的人
- 有請款單、核銷、代收抵扣流程的人
- 想要每月有預算紀律的人
- 想把存下來的錢和可支配餘額分開的人
- 需要備份 / 還原保障的人
