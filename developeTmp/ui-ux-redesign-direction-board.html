StrawMoneyBook · UI/UX redesign directions

把記帳從「填表」改成「掌握今天」

依照現有 Vue 介面與設計語彙製作：深色底、琥珀主色、底部導覽、卡片式行動 App。這份方向板不更動產品策略，而是提供三個可落地的視覺與互動方向，讓你挑選接下來要深入打磨的路線。

現有 tokens：#0d0d10 / #f5a623 / #34d399 核心頁：首頁、分析、資產、功能、設定 行動優先 · 44px 以上觸控 避免假數據與裝飾性圖表

共通 UX 原則

1. 首屏只回答三件事現在花多少、剩多少、下一步做什麼。降低首頁摘要的認知負荷。
2. 篩選要像「時間鏡頭」年 / 月 / 日 / 全部維持，但讓時間選擇更像瀏覽，而不是表單。
3. 收支不是只有數字用趨勢、預算壓力、交易脈絡輔助判斷，但避免憑空編造洞察。
4. 記帳入口必須永遠可見快速新增保留高優先權；進階功能收進導覽或命令式入口。

三個改版方向

從保守到發散：第一個最低風險，第二個是建議主方向，第三個用來探索更高效率的操作模型。

  • 首頁退居狀態概覽，工作台承擔操作中心。

我建議選 Option B

它最符合個人財務產品的日常價值：不是只記錄過去，而是幫使用者判斷今天是否安全、哪裡該注意。

實作拆分

  • 先改首頁首屏資訊架構。
  • 再把分析頁變成首頁卡片的下鑽結果。
  • 最後補強空狀態、錯誤狀態、載入骨架。

需要避免

  • 不要加入無來源的假洞察。
  • 不要讓圖表比決策更重要。
  • 不要為了新鮮感移除熟悉底部導覽。
